# Especificación visual

La fotografía de referencia se usa para reconstruir el certificado como HTML/CSS editable, sin incrustar la fotografía ni sus firmas.

## Estructura

1. Encabezado centrado: `Certificado de`.
2. Título grande: `Bautismo`.
3. Motivo azul de ondas.
4. Frase introductoria.
5. Nombre del bautizado con tipografía manuscrita.
6. Párrafo de certificación.
7. Cita bíblica y referencia.
8. Fecha + CIF.
9. Dirección.
10. Dos bloques de firma y marca central.
11. Barra inferior azul oscura.

## Campos editables

- textos
- nombre
- fecha
- CIF
- dirección
- cargos y nombres de firmantes
- colores
- marca superior/inferior
- plantilla completa vía JSON

## Privacidad

No se almacena la fotografía de referencia en el proyecto porque contiene datos personales y firmas manuscritas.
